# SaludConecta — Frontend Angular

Frontend del sistema de un centro médico ambulatorio. Angular 22, PrimeNG 22 (tema Aura) y Tailwind CSS 4.

- API: `http://localhost:4000/api` (backend `backend_express_saludconecta`).
- Desarrollo: `npm start` (puerto 4200).
- Validaciones: `npm test -- --watch=false` y `ng build`.
